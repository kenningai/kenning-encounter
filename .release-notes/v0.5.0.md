# v0.5.0 — governed infusion: memory that arrives on its own

Until now the agent had to *ask* its memory for anything: `orient` at
re-entry, `search` and the graph reads on demand. This release adds the
complementary channel — a governed, per-prompt **infusion** that surfaces
what the substrate already holds about the matter at hand, without being
asked, sized and disciplined so it informs rather than floods.

## The `infuse` tool

One read call per user prompt: **Extract → Match → Rank → Format.**

- **Extract** pulls focal signals from the prompt text (terms, identifiers,
  CIDRs, dotted hostnames).
- **Match** finds candidate nodes via the Lucene fulltext index.
- **Rank** runs a single biased personalized rank over an **ephemeral,
  coherence-only projection** — focal seeds at full weight, the epistemic
  frontier (open Questions, live Hypotheses) at a configurable minority bias
  — and compares against the unbiased mass so genuine tension surfaces
  first. The projection is created and dropped per call; nothing persists.
- **Format** emits a signed, budgeted payload: core conflicts lead, parked
  ones register briefly, the neighborhood follows.

`mode=delta` returns recognition/conflict only — and **silence is a valid
response**: if nothing new bears on the current step, nothing is injected.

## The renewal economy

Repetition is the failure mode of any always-on memory channel. The payload
pipeline now keeps a **per-session delivery ledger**: a node's full body is
delivered at first sight, on a changed fact-state, or after a staleness
horizon — otherwise it appears as a one-line handle in a STANDING register.
Edges follow the same discipline. The result, measured on replay: payloads
rotate with the work instead of droning a permanent core.

The assembler degrades honestly under budget: whole lines yield, never a
mid-line cut, and survival priority protects standing handles over fresh
bodies — a dropped body arrives next turn, while a dropped handle silently
withdraws an already-established node from the picture. The ledger is
stamped from what was **delivered**, never from what was merely selected,
and the renewal metadata reports both (`delivered_*` / `dropped_*`), with
each body's seed origin and the content's own age (`t_created` /
`t_observed`) alongside delivery age.

## Concept-cluster expansion

Keyword match cannot always reach the most on-point node: sometimes the
concept that *does* match is one authored coherence edge away from the one
that matters. Focal seeds now expand one hop across coherence edges from
matched Concepts, entering the rank at reduced bias. Reach improves,
measured on replay, while payload composition stays dominated by direct
matches — and the mechanism is **graph-native**: no embeddings, no vector
index, nothing vector-shaped ever stored. The invariant stands.

## Harness wiring

`scripts/agent_memory_infuse_hook.py` — a stdlib-only, fail-silent hook
client for Claude Code-style harnesses: full mode per user prompt, delta
mode per tool call, with a per-fact-state debounce so a recognition is
announced once, not echoed.

## Governors

- `NEO4J_INFUSE_FRONTIER_BIAS` (default `0.3`) — the frontier's minority
  weight in the biased rank.
- `NEO4J_INFUSE_REFRESH_TURNS` (default `10`) — the staleness horizon after
  which a standing node's body is re-delivered.
- `expansion_bias` (per call) — cluster-expansion weight; `0` disables.
- `frontier_mute` (per node, `Question`/`Hypothesis`/`Concept`) — excludes a
  node from every frontier surface, for retiring resolved lines of inquiry
  from the always-on channel.

## Also

- Read-only throughout: no schema change, no new node or edge types, nothing
  auto-written by the infusion path.
- 146 unit tests; the payload pipeline is pure-Python and tested without a
  database.
