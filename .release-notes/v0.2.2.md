# v0.2.2 — fresh-clone and fresh-build fixes

Packaging fixes so a clean clone and a clean image build both work out of the box. No change to the code, schema, or tools.

- **`.env.example` is now tracked.** The README opens the Docker stack with `cp .env.example .env`, but the template was never committed, so a fresh clone had nothing to copy. It is now in the repo (the real `.env` stays ignored).
- **The Docker image builds.** `pyproject.toml` declares `license = { file = "LICENSE" }`, so the build needs `LICENSE` in its context; the Dockerfile now copies it alongside `pyproject.toml` and `README.md`.
- **Valid Neo4j database name.** The default database is now named `agent-memory` (a Neo4j database name allows letters, digits, dots, and dashes — not underscores), so the stack starts cleanly instead of erroring on an invalid name.
