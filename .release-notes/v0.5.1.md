# v0.5.1 — the front door catches up (docs only)

v0.5.0 shipped governed infusion with detailed release notes and a stale
README — the changelog described the delta while the front door still
described the product without its always-on channel. A README is not a
changelog: it says what the thing *is*, and what the thing is changed.

- **README** — new section: *Governed infusion — memory that arrives on its
  own*. The two recall channels (asked-for via `orient`/`search`, unasked
  via `infuse`), the pipeline in one pass, the three disciplines that keep
  the channel honest (the renewal economy, silence-as-answer, graph-native
  reach), hook wiring, and the governors
  (`NEO4J_INFUSE_FRONTIER_BIAS`, `NEO4J_INFUSE_REFRESH_TURNS`,
  `expansion_bias`, per-node `frontier_mute`).
- **HOWTO** — new principle for the agent reading its own infused payloads:
  the signature and position-keeping, tension triage (core leads, parked
  register), what a STANDING handle means, silence as a valid answer, and
  the two disciplines the payload cannot enforce — name the governing
  concept in the move, and the displayed frontier is not your wondering.
  One new common-error to match.

No code change. The server is byte-identical to v0.5.0 except the version
string.
