# v0.4.0 — the analytics panel redesign: orient against feedback bias

An agent whose memory analytics feed its next writes is a feedback loop:
whatever the reading makes prominent gets written about more, which makes it
more prominent — rich-get-richer bias in the memory itself. This release
recomposes `orient`'s once-per-re-entry instrument panel against that loop.
Read-only throughout: no schema change, no new node or edge types, nothing
auto-written.

## orient — the new panel

- **mass** — ArticleRank replaces PageRank as the centrality reading: same
  family, damped hub transmission, mathematically weaker reinforcement.
- **frontier_mass** — PageRank personalized from the frontier (open Questions
  + untested Hypotheses; falls back to every frontier cut when those are
  empty; `seed_mode` reports which). The same graph ranked from what is
  unresolved instead of from what has accumulated.
- **divergence** — the bias detector: `well_suspects` are high in mass yet
  ignored by the frontier (prominent only by accumulation); `frontier_lifted`
  is the inverse (low-mass nodes the open work leans on). Only computable
  because both mass readings run.
- **leiden** — replaces Louvain for the community reading: guaranteed
  well-connected communities, no hallucinated clusters.
- **fragility** — new: articulation points + bridges. What disconnects the
  memory if removed — importance as load-bearing structure, not accumulation.
- **weave_audit** — new: local clustering coefficient read against degree.
  High-degree/low-clustering nodes are stars, not weaves — heavily referenced
  but never interconnected, exactly the shape feedback bias inflates.
- **drift** — new: the mass reading compared against an as-of-previous-session
  baseline (boundary = the latest session start; nodes and edges filtered by
  `t_created`, computed read-time, no writes). Risers, fallers, `new_since` —
  bias that is visible as movement is far easier to correct.
- **betweenness** and **wcc** retained. The frontier and unsealed sets ride
  along unchanged.

## Standalone GDS tools

- `gds_louvain` → `gds_leiden` (the Louvain defect — badly-connected
  communities — applies to focused reads too).
- Everything else stays general and agent-scoped by design: scoping the
  projection is how the agent formulates a focused question. The panel-frame
  readings (frontier seeding, divergence, drift) are `orient` constructions
  and get no standalone counterparts.

## Internals

- The panel arithmetic (`compute_divergence`, `compute_weave_audit`,
  `compute_drift`) is pure, DB-free, and unit-tested.
- A second reserved projection (`__agent_memory_orient_asof__`) for the drift
  baseline, dropped defensively and in `finally` alongside the main projection.
- HOWTO analytics principle rewritten around the feedback-bias framing and
  the new readings.
